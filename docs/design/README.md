  screenshots/
    screenshots-index.md
    SCR-01-onboarding.png

## Current note

The uploaded design package contained:

- `docs/design/Kintone-Site-Discovery-HiFi.html`
- `docs/design/screenshots/screenshots-index.md`

The screenshot index is stored in this repo. If PNG screenshots are needed for stricter visual parity, export and add the `SCR-*.png` files listed in `screenshots/screenshots-index.md`.

Codex should treat the high-fidelity HTML as the visual source of truth when present. The markdown specs in `docs/ui-handoff/` remain the source of truth for behavior, data, state, copy, and implementation constraints.
